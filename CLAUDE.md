# CLAUDE.md

## gstack — AI Automation & Vibe Coding Skills

Gstack provides AI-driven automation skills for the full software lifecycle: vibe coding, testing, reviewing, shipping, and deploying. Always use the `/browse` skill from gstack for all web browsing — never use `mcp__claude-in-chrome__*` tools.

### Planning & Review
- `/office-hours` — Generate a design doc with problem statement, premises, and alternatives
- `/autoplan` — Run the full review gauntlet (CEO + eng + design + DX + codex adversarial) on a plan
- `/plan-ceo-review` — CEO-level strategic review of a plan
- `/plan-eng-review` — Engineering feasibility and technical review
- `/plan-design-review` — Design and UX review
- `/plan-devex-review` — Developer experience review planning
- `/devex-review` — Developer experience review

### Vibe Coding & Design
- `/design-consultation` — Get a design consultation for a feature or change
- `/design-shotgun` — Rapid design exploration, generate multiple approaches quickly
- `/design-html` — Generate HTML/CSS from a design description
- `/design-review` — Review existing designs for issues
- `/codex` — Adversarial code review and edge-case hunting

### Code Review & Ship
- `/review` — Full code review before merging
- `/ship` — Create a PR with tests, changelog, and version bump
- `/land-and-deploy` — Land a PR and deploy it
- `/canary` — Set up and manage canary deployments

### Quality & Testing
- `/qa` — Full QA pass: find bugs, verify fixes, check coverage
- `/qa-only` — QA only mode — identify issues without fixing them
- `/benchmark` — Run performance benchmarks
- `/investigate` — Deep-dive investigation into a bug or incident

### Deployment & Infra
- `/setup-deploy` — Set up deployment configuration
- `/setup-browser-cookies` — Configure browser cookies for authenticated browsing
- `/setup-gbrain` — Set up gbrain integration

### Guardrails & Control
- `/careful` — Enable careful mode (extra verification before actions)
- `/freeze` — Freeze the codebase, prevent changes
- `/guard` — Guard mode, validate changes against rules
- `/unfreeze` — Unfreeze the codebase

### Documentation & Learning
- `/document-release` — Generate release documentation
- `/document-generate` — Generate project documentation
- `/retro` — Run a retrospective
- `/learn` — Learn from a codebase or pattern

### Browsing & Utilities
- `/browse` — Web browsing (always prefer this over `mcp__claude-in-chrome__*`)
- `/connect-chrome` — Connect to a Chrome browser instance
- `/cso` — Chief Security Officer review
- `/gstack-upgrade` — Upgrade gstack to the latest version

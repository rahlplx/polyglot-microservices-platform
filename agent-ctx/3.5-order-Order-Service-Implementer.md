## Key Design Decisions

1. **Domain core has ZERO external dependencies** — All domain types, ports, and services use only Kotlin stdlib
2. **State machine enforced at compile time** — `OrderStatus.requireTransition()` throws on invalid transitions
3. **Transactional Outbox** — All events written to same DB tx as order mutations; outbox relay polls at 100ms
4. **Choreography-based saga** — SagaOrchestrator tracks state but doesn't require centralized coordination
5. **Adaptive cancellation** — Cancellation saga steps are dynamically generated based on which forward steps completed
6. **Resilient clients** — All external calls wrapped with circuit breaker + retry + rate limiter
7. **SPIFFE mTLS** — Ready for zero-trust identity but gracefully degrades when disabled
8. **Manual DI** — No reflection framework, compile-time safe wiring

## State Machine
```
PENDING ──→ RESERVED ──→ PAID ──→ FULFILLING ──→ COMPLETED
  │           │           │           │                (terminal)
  ├──→ FAILED ├──→ CANCELLED  ├──→ CANCELLED  ├──→ CANCELLED
  │           │           │           │
  └──→ CANCELLED  └→ COMPENSATING ──→ CANCELLED
                              └──→ FAILED
```

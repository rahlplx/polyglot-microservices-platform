## Key Design Decisions

1. **Offline + Live Modes**: The mtls-verify.sh script supports `--skip-live` for validation without kubectl access, making it usable in CI/CD pipelines that don't have cluster access.

2. **Service Registry**: All 9 services are defined with language, port, and service account in both the bash script and Python conftest.py for consistency.

3. **13 Handshake Pairs**: Covers all critical cross-language paths (Go-Kotlin, Kotlin-TypeScript, Kotlin-Python, Python-Go, Rust-everything).

4. **Zero External Federation**: The federation policy explicitly defines no federated trust domains — all workloads must use `spiffe://trust.example.org/...` exclusively.

5. **spiffe.io/inject: "true" Label**: NetworkPolicy enforcement uses this label selector to target only SPIFFE-injected workloads, allowing non-SPIRE infrastructure (SPIRE agent, OTel collector, etc.) to function.
